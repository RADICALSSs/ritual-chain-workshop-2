Workshop Notes

  • Resolution is scheduled by block number, not by timestamp.
  • HTTP precompile reads the oracle URL.
  • jq precompile extracts the value from the response.
  • Failed oracle reads should not be counted as NO.
  • Winners claim payouts with a pull-based model.
